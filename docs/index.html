One message.
A complete loop.

SparkWA is a bridge to an existing Spark agent, not a standalone AI model. It verifies the sender, forwards requests through Gmail, and relays eligible replies to WhatsApp.

01 / INPUT◉WhatsApp

Send an instruction from the authorized personal number to the dedicated bot number.

02 / BRIDGE⌁SparkWA

The self-hosted Go process validates the sender, records task state, and prepares the message.

03 / TRIGGER✉Gmail

The Gmail API sends the task to a configured mailbox for the Spark workflow.

04 / RESPONSE↩Gemini Spark

The configured agent processes it and the response is relayed back to WhatsApp.

A few things
worth knowing.

Does SparkWA replace Gemini Spark?

No. SparkWA relays messages to a separately configured Gemini Spark agent via Gmail. You need to configure the Spark trigger and Gmail OAuth permissions following the documentation.

Does it require a browser or Node.js on the server?

The application is written in Go and distributed as a native executable. It does not require Node.js, Docker, or a persistent browser runtime. Setup uses your Google account for OAuth authorization.

Can anyone send commands to my bot?

The implementation documents a restricted sender-number allowlist. Review the security policy, WhatsApp account risk disclosures, and the Gemini approval flow before enabling it.

What if WhatsApp or Gmail stops working?

Open the troubleshooting guide and run sparkwa doctor. The guide covers session pairing, OAuth token errors, SQLite locks, and service failures.
