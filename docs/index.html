06 / QUESTIONS

A few answers.

Are these products part of one connected platform?

No. This site is a collection of independent products and projects by the same builder. Integrations are described on each project page only where documented.

Can I try everything in my browser?

Not necessarily. Some projects have sites referenced in their README; others provide source code, research artifacts, or local setup instructions. Check each project's access links.

Are all projects open-source or free?

Publicly visible source is not the same as an open-source license. Licensing, hosting costs, and any price details differ by repository. Follow each source link for the authoritative terms.

Where do the screenshots and visual assets come from?

From public project repositories identified on the detail pages. When authentic media is not available, the site uses typography-led editorial visuals rather than fabricated product interfaces.

Where can I find the original SparkWA documentation?

The original guide is preserved at SparkWA documentation, alongside its source repository and setup instructions.
