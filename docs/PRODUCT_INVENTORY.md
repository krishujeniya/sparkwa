## Deliberate limitations
- Each source link points to an actual repository in the authenticated GitHub account; a repository existing does not mean the product is deployed or commercially offered.
- Technologies and features are reported as descriptions from the repos, not independently verified operational outcomes.
- Images are externally hosted at raw.githubusercontent.com except the bundled SparkWA banner. Offline experiences degrade to descriptive typography.
- No invented screenshots, case studies, uptime, testimonials, subscription tiers, legal policies, or email address.
- Older/archived/less-described repositories were not included in this 20-product curated showcase.

## Route convention
GitHub Pages static routes: `/sparkwa/products/<slug>/`. Detail pages are generated from the registry by `docs/assets/ecosystem.js`.
